# Common Classes Information
This document provides general information about common classes used in the application.

## Card
Object representing a playing card, including properties such as suit, face, and value and imageUrl.

## Hand
Object representing a player's hand in a Black Jack game, containing an array of `Card` objects.

## LinkObj
Object representing a navigation link, including properties such as `name`, `path`, and `enable`. (In importance of this is to reduse hardcoding of navlinks throughout the app)

## NavLinks
Class containing static arrays of `LinkObj` for different navigation menus used in the application.
