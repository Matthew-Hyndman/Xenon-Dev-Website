My future plans for this Website

To streamline the development process, I have outlined several evolving phases with distinct technical goals:

Phase 1 (completed)
Host Website via Amazon Web Services with Amplify Gen 2 Features: Blackjack Game, Disclaimer, and Landing Page. All developed using Angular.

Phase 2 (Complete)
User accounts with security (Spring Boot and HTTPS), Blackjack record keeping (track wins, losses, and pot amount, in a database), and a leaderboards feature.
Services to be integrated:

Keycloak
A REST API would be utilized to facilitate the secure transmission and reception of data, thereby enabling account security. To access stored user information, a sign-in system is essential. Keycloak is a suitable and free solution for implementing online sign-in security.
I engineered a full backend using Spring Boot 3 REST API, integrating a custom MySQL database with Keycloak SSO authentication — managing schema security through a dedicated account and validating requests via JWTs and origin checks. I initially deployed this on AWS via EC2 and RDS, but at ~$45/month this proved unsustainable, so I pivoted to a serverless AWS-native stack using Cognito, Lambda, DynamoDB, and API Gateway, achieving a comparable result at negligible cost.
Beyond the architecture shift, I developed CRUD endpoints to track user-specific game data (wins, losses, and tokens), orchestrated a major migration from Angular v17 to v19 while resolving complex dependency conflicts, and proactively managed technical debt in response to AWS policy changes such as the deprecation of Node.js 18. Throughout, I prioritised reliability, security, and maintainability — debugging integration errors systematically and monitoring for supply-chain vulnerabilities across the project's dependencies.

Phase 3
Future Development: A mock eCommerce shop with customer accounts, enabling the creation of mock transactions to demonstrate a working payment process.
Service to be integrated:

Stripe (connected via REST API)

Phase 4
Future Development: A Progressive Web App that is a Sheep Tracker App that allows Farmers/Livestock owners to keep track of their sheep. This app will allow farmers to monitor the health, stage of life cycle and location of their sheep.
The most important aspect of this project is the offline functionality, as farmers may not always have access to the internet and most likely will only have a mobile device. Therefore, the app will be designed to function without an internet connection, allowing farmers to access and update their sheep information even in remote areas. When an internet connection is available, the app will sync data with a server to ensure that all information is up-to-date and accessible from multiple devices.
Lastly, if the farmer wishes to sell a sheep, the app will have a feature that allows them to list their sheep for sale on an online marketplace, connecting buyers and sellers in the agricultural community. When a sheep is sold, the app will update the farmer's inventory and provide a record of the transaction for their records.
