My future plans for this Website

To streamline the development process, I have outlined several evolving phases with distinct technical goals:

Phase 1 (completed)
Host Website via Amazon Web Services with Amplify Gen 2 Features: Blackjack Game, Disclaimer, and Landing Page—all developed using Angular.

Phase 1.5 (completed)
This phase is dedicated to fine-tuning user experience and ironing out bugs that derived from phase 1. See the following updates made:

  • Optimised HTML and CSS - Improved readability and standardisation
  • General UI update - New background and buttons
  • Black Jack UX Overhaul - The Black Jack game UI looked old and was still a bit difficult to understand, therefore I added:
    • Card tooltips that reveal the card value
    • Reworked buttons and spacing
    • A dealer card reveal timer (just for suspense)
    • A toggle for the dealer card reveal timer (just in case it gets annoying)
  • Toggle Dealer card reveal timer data stored - When you change the toggle the preference it will be remembered next time you visit the page (stored locally)
  • Black Jack bug fix - Black Jack had an issue with the Ace card being pulled and did not change its value accordingly. I utilised Jasmine unit testing to assist in finding all possible bugs that could happen.
